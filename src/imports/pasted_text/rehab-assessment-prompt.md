以下是为 **Coding Agent（代码助手 / AI 编程代理）** 设计的结构化需求 Prompt，可直接用于指导开发微信小程序版本及移动端 H5 版本的康复评估产品。已涵盖核心功能、业务边界、技术约束和交互细节，方便代理拆解任务与生成代码。

---

```markdown
# 任务：开发康复评估产品（微信小程序 + 移动端H5）

## 1. 项目概述
你是一位全栈开发专家，请根据下述需求，实现一个**数字康复评估平台**的前端部分，需同时支持**微信小程序**和**移动端 H5（SPA）**。   
产品核心流程：  
用户登录 → 完善个人档案 → 首页引导 → 病情采集（量表） → 设备连接与动作评估 → 生成诊断报告 → 推荐康复训练动作 → 后台管理看板（管理端）。

平台目标：通过视觉追踪与蓝牙设备结合，完成康复动作评估并自动出具报告。

---

## 2. 技术栈要求
- **跨端方案**：推荐使用 **Taro 3.x** 或 **uni-app** 实现一套代码多端运行（小程序 + H5）。
- **UI 框架**：可结合 **NutUI**（Vue3 + Taro）或 **TDesign** 保持双端一致性。
- **状态管理**：Pinia 或 Vuex（按所选技术栈搭配）。
- **动画**：评估过程中需使用 `Taro.createAnimation` 或 Lottie 动画展示 3D 指导动作。
- **图表**：报告页使用 ECharts（按需引入，支持小程序端）。
- **摄像头与蓝牙**：直接调用各平台原生能力（需做环境判断适配，H5 使用 Web Bluetooth API + navigator.mediaDevices ，小程序使用 `<camera>` 组件 + `wx.getBLEDevice` 系列 API）。
- **后端接口**：需假定后端已提供 RESTful API，你只需负责前端逻辑与页面实现，接口文档见附录模拟（可根据需求自行构造）。

---

## 3. 页面与功能清单（按模块拆分）

### 3.1 登录页
- **登录方式**
  - 手机号 + 验证码登录（国际区号选择，默认 +86）
  - 微信一键授权登录（仅小程序支持，H5 模拟微信网页授权）
  - 邮箱 + 密码登录
  - WhatsApp 登录（仅 H5 海外场景，以跳转外部链接或 OAuth 模拟）
- **协议**
  - 底部必须展示《隐私协议》《服务协议》勾选框（未勾选时登录按钮置灰）
  - 点击协议可打开对应 HTML 富文本模态框（内容由后端下发）
- **登录状态持久化**
  - 登录成功后存储 token，下次打开自动登录（跳过登录页）

### 3.2 个人档案页
- **输入字段**
  - 昵称（文本，必填）
  - 年龄 / 出生日期（日期选择器）
  - 性别（单选：男 / 女 / 非二元）
  - 身高（cm）、体重（kg），自动计算 BMI 并展示结果区间
  - 康复目标选择（疼痛缓解、术后恢复、体态改善等，可多选）
- **头像**：支持拍照/从相册选取，上传缩略图。
- **数据校验**：年龄 0-120，身高体重合理范围，未填时提示。

### 3.3 首页
- **布局**：顶部可滑动 Banner（占位图片），中部为功能网格入口。
- **入口卡片**：
  - 开始康复评估（动作评估）
  - 我的康复计划（推荐动作）
  - 健康报告（历史报告）
  - 设备配置
- **个性化建议卡片**：根据用户档案和最近一次评估结果展示一句话建议（如“建议每日完成肩部放松训练”）。
- **今日待办区域**：应完成的训练项目数、评估任务（状态标签）。

### 3.4 病情采集表单
- **多步骤表单**（可拆分为 3-4 步）
  - 步骤1：症状部位选择（身体正面/背面图矢量点选，支持多部位）
  - 步骤2：疼痛 VAS 评分（滑块 0-10），症状描述（文本框）
  - 步骤3：病史采集（多选框组：遗传病、既往手术、过敏史等）
  - 步骤4：标准化量表（根据部位动态加载，如 ODI、DASH，题目为单选题或程度选择题）
- **交互要求**
  - 进度条显示
  - 支持中途退出自动保存草稿（本地 + 后台）
  - 必须项校验
  - 提交时若触及**预警阈值**（如 VAS ≥ 7、特定量表分过高），立即弹窗警告并建议联系医生。
- **数据上传**：所有表单答案按结构体提交。

### 3.5 动作评估（核心功能）
- **前置条件**：必须完成设备连接（见3.6），若未连接则引导跳转。
- **评估流程**
  - 展示当前动作教学视频（示例动作：颈屈伸、肩外展等）
  - 启动摄像头追踪（H5 要求用户授权摄像头，小程序直接使用 `<camera>`）
  - 用户按提示做动作，界面实时显示：
    - 完成次数 / 要求次数（如 3/5）
    - 动作角度实时曲线（模拟传感器数据）
    - 智能评分（以进度环或百分数展示）
  - 动作不达标时语音提示“请肩部抬高一点”等（使用 TTS 或预录音频）
- **控制按钮**
  - 重试：重新计数当前动作
  - 跳过：跳过当前动作进入下一个
  - 暂停/继续
- **特殊处理**
  - 摄像头画面需加关键骨骼点连线动画（模拟）
  - 评估结束后，所有数据传到后端，并显示“评估完成”页面。
- **异常处理**
  - 光线不足：弹提示调整环境
  - 用户离开摄像头范围：计时 3 秒后暂停并提示
  - 蓝牙设备断开：自动暂停评估并重连

### 3.6 设备配置
- **Pad 配网**（此处简化，仅展示模拟流程）
  - 扫描二维码绑定设备（提供二维码生成方式模拟）
  - 显示设备在线状态（绿点/红点）
- **蓝牙设备连接**
  - 搜索周边 BLE 设备（过滤康复设备 UUID 前缀）
  - 列表显示设备名称、信号强度（RSSI）
  - 一键连接，连接成功后显示设备详情（电池电量、固件版本）
  - 连接断开时重连机制（最多 3 次）
- **按摩功能控制**（模拟面板）
  - 模式选择（列表）
  - 强度滑块（0-10）
  - 计时设置
  - 启动/停止按钮，包含急停按钮（红色）
- **数据采集校准**
  - 零点校准按钮，点击后发送校准指令，等待反馈。

### 3.7 诊断报告
- **报告结构**
  - 头部：用户姓名、评估日期、评估类型
  - 量化结果：雷达图展示（关节活动度、对称性、稳定性等）
  - 历史趋势：折线图显示与上次评估对比
  - 问题诊断列表（严重程度标签：轻度/中度/重度）
  - 康复建议文本及推荐动作列表（可跳转至动作详情）
- **操作**
  - 分享给微信好友（小程序用 `<button open-type="share">`）
  - 保存为图片（使用 canvas 绘制报告截图，需兼容 H5 和小程序）
  - PDF 预览/下载（H5 使用 window.print()，小程序使用 webview 或后端生成）

### 3.8 推荐动作与视频
- **推荐列表**
  - 每个动作卡片包含：缩略图、动作名称、难度标签、预计时长
  - 点击进入动作详情，包含：
    - 教学视频（支持全屏）
    - 文字步骤说明及注意事项
    - 3D 解剖动图（可用骨骼动画模拟）
- **训练跟练模式**
  - 一键开始跟练，调用摄像头进行简单动作计数（如深蹲次数），并播放节拍音效。
- **训练记录**
  - 日历视图打卡，统计每周完成情况。
- **激励**：连续 7 天打卡弹窗勋章。

### 3.9 后台数据分析（管理端，此处仅设计页面入口）
- 此项为后台功能，你需要实现一个简易管理后台的移动端界面（仅用于展示，可简化），包括：
  - 关键指标卡片（总用户、活跃率、评估完成数）
  - 示例图表（柱状图：各康复阶段人数）
- 该页面仅管理员角色可见（通过 token 中权限字段判断）。

## 4. 非功能性需求
- **性能**
  - 页面首屏加载时间 < 1.5s（3G 网络）。
  - 动作评估过程中摄像头帧率不低于 15fps，避免 UI 卡顿。
- **兼容性**
  - 微信小程序基础库版本 ≥ 2.10
  - H5 支持 iOS Safari 12+、Android Chrome 68+
- **安全性**
  - 所有 API 调用携带 JWT token
  - 敏感信息（病史、量表数据）传输加密，本地存储加密（可用 CryptoJS 简单实现）
  - 页面长时间停留（5分钟）无操作，Token 失效后跳转登录
- **国际化**
  - 支持中/英文切换（语言包通过 i18n 管理，至少首页和登录页可切换）

## 5. 界面与交互规范
- 遵循 Android / iOS 人机界面指南，使用本机风格组件（如分段器、弹出框等）。
- 主色调：医疗健康蓝 `#2E86DE`，辅助色柔和绿 `#10AC84`。
- 字体：系统默认中文字体，标题 18px，正文 14px。
- 按钮圆角 8px，卡片阴影轻微，留出充足间距。
- 所有可点击区域不小于 44x44pt（符合触摸友好）。
- 加载状态：全局统一的骨架屏（列表卡片）或加载动画圆圈。
- 错误状态：当接口错误时，显示错误插画 + “点击重试”按钮。

## 6. 边界状况（Edge Cases）全覆盖
在每个模块中已提及部分，整体需额外处理：
- **网络中断**：所有请求失败时，统一 toast 提示“网络异常，请检查连接”，并中断当前操作（如下拉刷新等待网络恢复）。
- **数据为空**：报告页无历史报告时，展示空状态插画 + “去完成首次评估”按钮；推荐列表空时展示“暂无推荐，请联系康复师”。
- **权限拒绝**
  - 摄像头权限拒绝：显示引导开启权限的设置页面入口（仅小程序有权限引导，H5 显示说明文字）。
  - 蓝牙权限拒绝：提示去系统设置打开。
- **异常数值输入防护**：所有输入框防止注入，数字输入框限制范围。
- **多媒体加载失败**：视频/图片加载失败使用占位图，并提供“重新加载”功能。
```
